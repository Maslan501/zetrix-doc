# Zetrix Official Release Notes

## Zetrix Node Release Information

### Node & Network Updates

This page provides the official release information for **Zetrix node updates**.

It serves as a central reference for node operators to track changes, upgrades, configuration updates, and network version changes released for Zetrix nodes.

***

### Release Updates

Each release entry provides the key information required to understand and apply a Zetrix node update.

#### Release Information

Each release may include:

* **Release Title** — A short description of the update
* **Completion Date** — Date the release was completed
* **Status** — Current release status
* **Description** — Overview and purpose of the update
* **Changes** — Configuration, performance, or functional changes
* **Version Updates** — Ledger and Chain version changes
* **Upgrade Information** — Additional requirements or actions for node operators

#### Release Status

| Status                 | Description                                        |
| ---------------------- | -------------------------------------------------- |
| 🟡 **In Progress**     | Release is currently being implemented or deployed |
| 🔵 **Scheduled**       | Release is planned for deployment                  |
| 🟢 **Completed**       | Release has been successfully completed            |
| 🔴 **Required Action** | Node operators are required to take action         |

***

### Release History

All completed and upcoming node releases are documented on this page in chronological order.

Node operators should review the latest release information before performing any node upgrade or configuration change.

> **Important:** Always review the applicable release information and upgrade requirements before updating a production node.
